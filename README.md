🛒 E-Commerce Website (Django)

A fully functional e-commerce web application built with Django, featuring product browsing, categories, brands, search functionality, cart management, user authentication, and order processing.

🚀 Features
🛍 Product & Category System

Browse products by category and brand

Detailed product page with images, description, price, and stock

🔍 Search

Product search with keyword matching

🛒 Shopping Cart

Add / remove items

Update quantity

Total price & checkout summary

👤 User Accounts

Register, login, logout

User profile & order history

💳 Checkout System

Billing & shipping form

Order placement

Payment integration (Stripe/PayPal optional)

📦 Admin Features

Full control via Django Admin

Manage products, categories, brands

Manage orders & users

🏗 Tech Stack

Python 3

Django

HTML, CSS, JavaScript

Bootstrap / Tailwind (optional)

SQLite / MySQL / PostgreSQL

Pillow for image handling
